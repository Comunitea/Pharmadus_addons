Overview
--------

The **Pharmadus Base** module provides comprehensive product specification management
for Pharmadus Botanicals' Odoo ERP system (v18.0 CE). It extends core Odoo modules
with company-specific catalog structures, stock lot tracking, and custom sales/purchase workflows.


Key Features
------------

- **Hierarchical Product Catalog**: Lines → Sublines with multi-company support  
- **Stock Management**: Advanced lot creation wizard with packaging counts  
- **Sale Transfers**: Distributor order quotations with auto-reporting  
- **Purchase Organization**: Functional procurement categorization  (components, logistics, raw materials)  
- **Enhanced Reports**: Sale/Purchase/Inventory analytics with Pharma-specific dimensions  


Quick Start
-----------

1. Install module via Odoo Apps menu  
2. Navigate to **Especificaciones > Líneas** to define product catalog  
3. Use "Crear lote" button on incoming pickings for batch registration  


For detailed usage, see :doc:`USAGE.md`
